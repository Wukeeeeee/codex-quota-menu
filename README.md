# ChatGPT Quota Menu

在 Windows 版 ChatGPT 桌面客户端顶部菜单栏的“说明”旁显示 5 小时和 7 天额度、SVG 圆环、重置时间与倒计时。

> **当前是实验原型。** 已在 Microsoft Store 版 `OpenAI.Codex 26.1021.3705.0` 上看到额度菜单；尚未验证原始快捷方式启动、应用更新后的适配和回滚。此项目不是 OpenAI 官方插件，也不受 OpenAI 支持。

## 重要：启动方式与签名

这个版本会在本机生成一个独立的 ChatGPT 客户端副本，并修改副本内的 `app.asar` 与对应完整性记录。它不会修改 WindowsApps 中的官方安装，但副本不再保留 OpenAI 原始数字签名。

要显示菜单，首次冷启动必须使用本项目生成的 **ChatGPT Menu** 快捷方式（或双击 `ChatGPT Menu.vbs`）。官方快捷方式不会在冷启动时加载此补丁；官方客户端已经运行时，官方图标可能只会把同一进程切回前台。请先完全退出官方客户端再启动补丁副本。

## 安装和启动

需要 Windows、Microsoft Store 版 ChatGPT/Codex 桌面客户端，以及已加入 `PATH` 的 Node.js。

1. 下载或克隆本仓库。
2. 在仓库目录打开 PowerShell，运行下面这一条。脚本会创建 **ChatGPT Menu** 快捷方式并启动客户端副本：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. 后续冷启动请使用 **ChatGPT Menu**。如果看到“请先退出”，从系统托盘完全退出官方客户端后重试。

额度栏读取客户端原有的额度响应，不调用模型。圆环百分比代表剩余额度；5 小时和 7 天的重置倒计时会自动更新，额度数据大约每两分钟刷新一次。

## 卸载

在仓库目录运行下面这一条。它会尝试关闭本项目客户端、移除本项目快捷方式，并删除生成的客户端副本和缓存；仓库源码会保留。若要删除源码，再手动删除整个仓库目录。卸载不会移除或改动官方 ChatGPT：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

若要恢复官方客户端，用原来的官方入口启动。项目不会替换官方快捷方式。

## 已知限制

- 原始快捷方式冷启动集成尚未实现；这是独立副本启动器，不是可自动附加到官方进程的插件。
- 只在上面列出的客户端版本验证显示效果。官方更新可能改变内部脚本结构，导致构建停止或需要适配。
- 已知启动/构建流程尚无完整事务回滚；更新中断、同时启动、同版本重建等场景未验证。
- 官方版与补丁副本默认共享用户数据目录；不要同时运行，也不要把本项目用于保存重要数据的唯一客户端。
- 修改后的副本不具有 OpenAI 原始签名。不要分发生成的 `client/` 文件或任何官方二进制；本仓库只含项目源码。

## 开发和检查

修改前请关闭所有 ChatGPT/Codex 桌面进程。构建器依赖当前官方应用内的打包文件格式及内部函数结构；版本不兼容时会报错并停止。不要通过关闭 Windows 或应用的安全校验来处理失败。
